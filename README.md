# 🎬 YouTube AI Studio

> Plateforme intelligente de création automatisée de chaînes YouTube, génération de vidéos IA et publication autonome via l'API officielle YouTube Data v3.

---

## 🚀 Fonctionnalités Clés

### 1. Création de Chaînes YouTube avec l'IA
- **Génération automatique de noms percutants** selon la niche choisie.
- **Logos & Bannières IA** créés sur mesure et adaptés aux formats YouTube.
- **Descriptions optimisées SEO** avec mots-clés stratégiques.
- **Support multi-niches :** Motivation, Histoire, Football, Actualités, Éducation, Divertissement, Business, Technologie, Gaming, Santé.
- **Multi-chaînes :** Connexion et gestion centralisée de plusieurs comptes YouTube.

### 2. Générateur Automatique de Vidéos IA
- **Idée $\rightarrow$ Vidéo Complète en 1 clic.**
- **Scripts structurés :** Accroche virale (Hook), Corps narratif, Climax, et Appel à l'action (CTA).
- **Voix Off Réalistes :** Moteur neural multilingue (voix françaises et internationales avec contrôle de tonalité et vitesse).
- **Sous-titres synchronisés automatiques :** Incrustation dynamique style Karaoké.
- **Musique de fond libre de droits :** Presets épique, lofi chill, tech et mystère avec mixage intelligent.
- **Formats supportés :** Vidéos Longues (16:9 - 1920x1080) et YouTube Shorts (9:16 - 1080x1920).
- **Miniatures professionnelles :** Générateur canvas en haute résolution (1280x720) avec badges viraux et contrastes néon.
- **Export direct :** Téléchargement instantané MP4/WebM.

### 3. Publication Automatique sur YouTube
- **Connexion officielle Google Cloud OAuth 2.0 & YouTube Data API v3.**
- **Publication en 1 clic :** Envoi immédiat ou programmation à date et heure fixe.
- **Génération automatique :** Titres viraux, descriptions avec chapitrage horodaté et tags SEO.
- **Gestion des statuts :** Brouillon, En file d'attente, Programmé, Publié.

### 4. Tableau de Bord & Analytics
- Statistiques globales (chaînes, vidéos créées, vidéos publiées, vues cumulées, abonnés).
- Suivi du solde de crédits IA.
- Calendrier interactif des publications mensuelles.

### 5. Mode Pilote Automatique (Autopilot)
- Fréquence hebdomadaire personnalisable (1 à 7 vidéos par semaine).
- Agent autonome de veille et sélection des sujets tendances.
- Chaîne de génération automatique sans intervention requise.

---

## 🛠️ Installation & Démarrage

### 1. Démarrer le serveur de développement :
```bash
npm run dev
```
Ouvrez ensuite [http://localhost:3000](http://localhost:3000) dans votre navigateur.

### 2. Compiler pour la production :
```bash
npm run build
npm run start
```
